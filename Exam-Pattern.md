# 📘 Machine Learning Exam Pattern

This guide provides a clear overview of the typical Machine Learning (ML) certification/exam structure to help you prepare effectively.

# ✅ 1. Total Questions

120–150 questions in total
All questions contribute to the final score

# ✅ 2. Question Types

Multiple Choice Questions (MCQs)

Scenario-based / application-oriented questions

Numerical problem-solving questions

Code interpretation questions

Some questions may require selecting multiple correct answers

# ✅ 3. Exam Duration

150–180 minutes
(No scheduled breaks in most exam formats)

# ✅ 4. Exam Format

Computer-Based Exam (CBE)
You can take the exam:

Online (Proctored mode)

At authorized test centers

# ✅ 5. Domain-wise Weightage
Domain	Weight
Supervised Learning	35%
Unsupervised Learning	20%
Deep Learning Foundations	25%
Data Preprocessing & Feature Engineering	10%
Model Deployment & MLOps Basics	10%

(Percentages may vary depending on the certification provider.)

# ✅ 6. Difficulty Level

Moderate to high difficulty

Strong emphasis on mathematical understanding

Tests knowledge of ML algorithms, model evaluation, and practical application

Some scenario-based and coding-style questions to assess real-world problem-solving

# ✅ 7. Passing Score

Most ML certifications do not specify an official passing score.
Recommended target: 70–80% correct answers to ensure a safe pass.

# ✅ 8. Exam Retake Policy

Typically:

Up to 3 attempts allowed within one exam cycle

Mandatory cooling period (varies by exam provider)
